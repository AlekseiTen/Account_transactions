💳 Виджет «Операции по счетам»
📘 Описание проекта

Проект реализует backend-логику для виджета, который отображает последние банковские операции клиента в личном кабинете банка.
Это часть функционала реального банковского приложения, отвечающая за обработку и подготовку данных для отображения в интерфейсе пользователя.

Функция получает список всех операций клиента из JSON-файла, фильтрует только выполненные (EXECUTED), сортирует их по дате и возвращает 5 последних операций в удобочитаемом виде.

Проект создан исключительно на Python, без использования сторонних фреймворков — это демонстрация чистого подхода к backend-разработке и применения принципов ООП и чистого кода.

🧠 Основная задача

Реализовать алгоритм, который выводит 5 последних успешных операций клиента в формате:

14.10.2018 Перевод организации
Maestro 1596 83** **** 5199 -> Счет **9589
31957.58 руб.

🧩 Функциональные возможности

Чтение данных из JSON-файла.

Фильтрация только выполненных операций (EXECUTED).

Сортировка по дате в порядке убывания.

Маскирование номеров карт и счетов:

Карта: XXXX XX** **** XXXX

Счёт: **XXXX

Форматирование даты в виде ДД.ММ.ГГГГ.

Отображение 5 последних операций клиента.

Обработка возможных отсутствующих данных (from может отсутствовать).

🧱 Принципы разработки

ООП-подход — каждая операция реализована как отдельный объект.

SOLID и чистый код — каждая функция не превышает 50 строк, отвечает за одно действие.

Модульность — код разделён по слоям: модели, утилиты, сервисы.

Тестируемость — функции легко покрываются unit-тестами.

Минимализм — проект не использует фреймворки (только стандартная библиотека Python).

💼 Цель проекта

Этот проект демонстрирует:

Владение Python и принципами backend-разработки;

Умение проектировать архитектуру и структурировать код;

Работа с JSON, форматированием, датами и тестированием;

Применение ООП и SOLID на практике.
